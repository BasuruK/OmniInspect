SurfaceRisk*Impact / control

Contain the rollout

Make bridge opt-in. Keep direct HTTP available. Start with one IDE; validate restart, delayed startup, setup forms and uncertain mutations.

Rollback & limitation

Restore the IDE’s direct HTTP configuration. Credential migration needs its own rollback. After reboot, the IDE must launch the bridge again.

Evidence: server restart reproduced 404 with old session, 200 with unchanged bearer on fresh initialization. Bridge recovery and actual IDE behavior remain untested.
